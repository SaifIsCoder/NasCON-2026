# Mobile Application (NaSCon ’26 Part I)

## Platform Requirements (Section 8.1)
- Target: Android (min API 29 / Android 10+) or iOS.
- Deliverable artifact: `mobile/release/app-release.apk` (Android).
- Required screens (Section 8.2):
  1. Login (Email + Password, role-aware)
  2. Fixtures (List of matches with real-time status and time)
  3. Match detail (Live score, event timeline, pinned merchandise showcase)
  4. Standings (Points table with qualification status)
  5. Club profile (Club info, roster, staff, home venue)
  6. Merchandise Store (Catalogue, variant picker, cart, mock payment checkout, receipt viewer)
  7. Roster management (For Club Manager: add/transfer/loan/release)
  8. Scoring entry (For League Organizer: append score & compensating events)
  9. Sync status (Online/offline/syncing indicator and pending offline action queue)
